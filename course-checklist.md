Картинки Star Pizza взяты из ZIP курса. Для блюд, не имеющих точного соответствия в архиве, использованы иллюстративные фотографии из того же набора. Маленькие изображения пасты и напитков уменьшены из больших файлов; каждая картинка открывает большой вариант. CSS на этих страницах не используется.

**Личная ссылка:** в футерах учебных личных сайтов пока стоит главная GitHub. Перед сдачей замени её ссылкой на свой профиль. Email уже указан из CV.

### Как выполнить упражнение с DevTools

1. Открой настоящую страницу с текстом, например статью Wikipedia.
2. Нажми **F12** или правой кнопкой по тексту → **Inspect**.
3. Во вкладке **Elements** найди заголовок. Дважды нажми на его текст и впиши шуточный вариант.
4. При желании сделай снимок экрана.
5. Обнови страницу: исходный текст вернётся. Эти изменения существуют только в твоём браузере.

## Перед сдачей First Project

- [ ] Заменить GitHub в учебных футерах на свой профиль.
- [ ] Проверить данные About Me и CV, включая название колледжа на английском.
- [ ] Разобрать HTML и CSS так, чтобы объяснить их на экзамене.
- [ ] Проверить главные страницы при 375px, 768px и 1024px в браузере.
- [ ] Проверить HTML и CSS в валидаторах W3C.
- [ ] Загрузить содержимое проекта в публичный репозиторий и включить GitHub Pages.
- [ ] Открыть опубликованный сайт и проверить ссылки.
- [ ] Сдать адрес через itslearning до срока преподавателя.

Игры и комментарии не являются содержимым портфолио. Отметить их выполненными можно после самостоятельной практики.
