# Как разобраться в коде

Начни с `projects/01-html/star-pizza.html`. Потом открой три версии личного сайта по порядку: `01-html/introduce-yourself`, `02-css/personal-site`, `03-layout/personal-site`. Так ты увидишь, что добавляет каждый этап. Основное портфолио разбирай после них.

## 1. HTML: что находится на странице

В `star-pizza.html` нет подключения CSS. Браузер показывает стандартные заголовки, списки и ссылки.

```html
<section>
  <h2>Pasta</h2>
  <ul>
    <li>
      <h3>Creamy Mushroom Pasta</h3>
      <p>Pasta with mushrooms and a creamy sauce.</p>
    </li>
  </ul>
</section>
```

`section` объединяет одну тему — раздел меню. `h2` — заголовок раздела, `h3` — название блюда. `ul` — ненумерованный список, `li` — один его пункт. Пиццы находятся в `ol`, потому что в исходном задании они пронумерованы.

Теги должны закрываться в обратном порядке: сначала `li`, затем `ul`, затем `section`.

| Тег | Зачем он здесь |
| --- | --- |
| `head` | Настройки документа и заголовок вкладки |
| `title` | Текст вкладки браузера |
| `body` | Видимое содержание |
| `header` | Название и верхняя часть страницы |
| `nav` | Ссылки для перехода между страницами |
| `main` | Основное содержание |
| `section` | Раздел с общей темой |
| `article` | Самостоятельная карточка проекта или запись CV |
| `aside` | Дополнительная информация — например, навыки рядом с CV |
| `footer` | Контакты и нижняя часть страницы |

В именах файлов использованы маленькие буквы и дефисы. Это помогает одинаково обращаться к файлам на компьютере и на GitHub Pages.

## 2. Ссылки и изображения

В Star Pizza маленькая картинка вложена в ссылку:

```html
<a href="../../images/exercises/star-pizza/margherita-big.jpg"
   target="_blank" rel="noopener">
  <img src="../../images/exercises/star-pizza/margherita-small.jpg"
       alt="Course photo illustrating Margarita pizza">
</a>
```

`src` — изображение, которое видит посетитель. `href` — большой файл, который откроется после нажатия. `target="_blank"` открывает новую вкладку или окно — это решает браузер. `rel="noopener"` не даёт новой вкладке управлять исходной. `alt` описывает изображение, если оно не загрузилось, и помогает людям, использующим экранный диктор.

Каждое `../` поднимается на одну папку выше. Из `projects/01-html/star-pizza.html` два подъёма приводят в корень сайта, где лежит `images`.

На главной странице путь короче: `images/profile-image.png`, потому что `index.html` уже находится в корне.

## 3. Таблица

В `introduce-yourself/interests.html` таблица показывает интересы.

- `table` — вся таблица.
- `caption` — её название.
- `thead` — строка заголовков, `tbody` — данные.
- `tr` — одна строка.
- `th` — ячейка заголовка, `td` — обычная ячейка.
- `scope="col"` связывает заголовок со столбцом, `scope="row"` — со строкой.

Таблица подходит для связанных данных по строкам и столбцам. Для раскладки сайта используются Flexbox и Grid.

## 4. Как CSS подключается к HTML

В `02-css/personal-site/index.html` появилась строка:

```html
<link rel="stylesheet" href="style.css">
```

HTML загружает отдельный CSS-файл из той же папки. Все три страницы подключают один файл, поэтому цвет, шрифт и таблица оформляются одинаково.

```css
h2 {
  color: var(--accent);
}
```

`h2` — селектор: правило действует на все заголовки этого типа. В фигурных скобках находятся свойства. `color` отвечает за цвет текста.

В основном сайте `.project-card` выбирает элементы с `class="project-card"`. Класс можно повторять. `#main-content` выбирает один элемент с таким `id`; в пределах документа идентификатор должен быть уникальным.

`a:hover` действует при наведении мыши. `a:focus-visible` выделяет ссылку при переходе по клавише Tab. `a[aria-current="page"]` выделяет ссылку на открытую страницу.

## 5. Зачем нужны CSS-переменные

```css
:root {
  --accent: #235c89;
}

a {
  color: var(--accent);
}
```

`:root` выбирает корневой элемент документа. `--accent` — имя переменной, `var(--accent)` — подстановка её значения. Если заменить цвет в одном месте, все использующие его элементы изменятся. Переменные прямо требуются в задании Even More You.

## 6. Margin, padding, border и box-sizing

Представь коробку:

- `width` — ширина содержимого при обычном `content-box`.
- `padding` — место между содержимым и рамкой.
- `border` — рамка.
- `margin` — расстояние до соседних элементов.

В `02-css/box-sizing.css` первая коробка имеет:

```css
width: 400px;
padding: 50px;
border: 10px solid;
```

Общая ширина до внешнего края рамки: **400 + 50 + 50 + 10 + 10 = 520px**. Отступ `margin` снаружи и не входит в эти 520px.

У второй коробки стоит `box-sizing: border-box`. Теперь `width` включает и содержимое, и padding, и border. Поэтому для одинаковой общей ширины второй коробке задано `width: 520px`.

В главном `css/styles.css` правило `* { box-sizing: border-box; }` применяется ко всем элементам. Так удобнее рассчитывать размеры колонок и карточек.

## 7. Ответы на Sizing Units

Базовый пример лежит в `projects/02-css/sizing-units.html`. Меняй одну строку за раз в соседнем CSS, сохраняй и смотри результат.

| Вопрос | Что происходит |
| --- | --- |
| Увеличить `html` с 16px до 20px | Внешний текст `2em` станет 40px, потому что наследует размер родителя. Внутренний текст `2rem` тоже станет 40px, потому что зависит от корня. Фиксированные ширины в px сохранятся. |
| Заменить внутренние `50%` на `200px` | При внешней ширине 400px результат одинаков: 200px. Если изменить внешнюю ширину, проценты пересчитаются, а 200px останутся фиксированными. |
| Заменить внутренние `2rem` на `2em` | При базовых 16px внешний текст равен 32px; внутренние `2em` дадут 64px. `2rem` давали 32px. Для `font-size` единица em опирается на размер шрифта родителя. |
| Какая единица меняется при изменении окна? | Проценты меняются вместе с размером родителя, если он зависит от окна. В исходном примере внешний блок фиксирован в px, поэтому его внутренние 50% тоже не изменятся при сужении окна. |
| Почему rem удобен для текста? | Он опирается на один корневой размер и не увеличивается повторно при вложенности, как em. |
| Что плохо в использовании px везде? | Фиксированные размеры блоков могут не помещаться на телефоне. Текст в px хуже учитывает изменение базового размера шрифта пользователем; увеличение масштаба браузера при этом работает. |
| Когда использовать px? | Например, для тонкой рамки или точного размера небольшого декоративного элемента. |

Эти два упражнения специально сохраняют фиксированные размеры исходного задания. Горизонтальная прокрутка на маленьком экране здесь показывает поведение px.

## 8. Flexbox: элементы в ряд

В `02-css/navigation/style.css` навигация сделана через `display: inline`. В разделе 03 то же упражнение переделано на Flexbox:

```css
nav ul {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
}
```

- `display: flex` размещает пункты по основной оси, по умолчанию в ряд.
- `flex-wrap: wrap` переносит их на следующую строку, если места не хватает.
- `justify-content: center` ставит пункты по центру ряда.

В упражнении Tag Arrangement дополнительно задан `gap: 0.25rem`: одинаковое расстояние между тегами.

В главном портфолио Flexbox используется для логотипа и навигации, кнопок и списков технологий. `align-items: center` выравнивает элементы поперёк ряда, поэтому логотип и текст стоят по одной линии.

## 9. Grid: колонки и строки

В `03-layout/responsive-grid.css`:

```css
.grid {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

`minmax(250px, 1fr)` говорит: колонка не уже 250px, а оставшееся место делится равномерно. `auto-fit` выбирает, сколько колонок поместится. `repeat` повторяет правило. `aspect-ratio: 1 / 1` в `.card` сохраняет квадратную форму карточки.

В Holy Grail используется другой способ:

```css
grid-template-areas:
  "header header header"
  "left main right"
  "footer footer footer";
```

Каждая строка описывает ряд сетки. Повторяющееся имя растягивает область на несколько ячеек. `grid-area: header` помещает шапку в область `header`. В `auto 1fr auto` боковые колонки занимают место по содержимому, а центральная получает оставшееся пространство.

В Stacking фото и список тегов получают одно имя `grid-area: stack`. Поэтому они занимают одну ячейку и перекрываются. `z-index: 1` поднимает теги поверх фотографии.

## 10. Media queries: когда менять раскладку

В `03-layout/breakpoints.css` сначала спрятаны все три заголовка. Затем показывается один в нужном диапазоне:

| Ширина окна | Видимый заголовок |
| --- | --- |
| До 480px включительно | Mobile |
| 481–1024px | Tablet |
| От 1025px | Desktop |

В основном портфолио используется другая схема — mobile-first. Сначала написана одна колонка. Затем добавляются правила:

```css
@media (min-width: 768px) {
  .project-grid { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .project-grid { grid-template-columns: repeat(3, 1fr); }
}
```

Поэтому при 375px карточки идут в одну колонку, при 768px — в две, при 1024px — в три. На 1024px подходят оба media query; последнее правило для той же сетки задаёт три колонки.

## 11. Почему нужны viewport и max-width

В EcoBottle строка в `head`:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Она сообщает мобильному браузеру использовать ширину устройства для раскладки. Без неё телефон может рассчитывать страницу как большой экран, а потом уменьшать её.

`main { max-width: 1000px; margin: 0 auto; }` ограничивает строку текста и центрирует содержимое. `img { max-width: 100%; height: auto; }` позволяет картинке уменьшаться по ширине и сохранять пропорции.

В основном портфолио `.container` использует `width: 90%` и `max-width: 1120px`: по бокам остаётся место, а на большом мониторе текст не растягивается бесконечно.

## 12. Что попробовать самостоятельно

1. В `css/styles.css` измени `--accent` и посмотри, какие элементы поменяли цвет.
2. В Star Pizza добавь ещё один пункт списка по образцу.
3. В упражнении Box Sizing убери `width: 520px` у `.alternate` и сравни коробки.
4. В Tag Arrangement убери `flex-wrap: wrap`, потом верни его.
5. В главном портфолио временно замени три колонки на две в последнем media query.
6. В Chrome открой **F12 → Elements**, нажми на элемент и посмотри вкладку **Styles**: там видно, какое правило CSS к нему применяется.

Меняй одну вещь за раз. Тогда ты увидишь причину изменения и сможешь объяснить её на экзамене.
